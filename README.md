# 職業探索サービス「しごとくじ」

[![IMAGE ALT TEXT HERE](https://jphacks.com/wp-content/uploads/2026/07/IMG_5316.png)](https://www.youtube.com/watch?v=piaNsc6ilBI)

## 製品概要
### 背景
多くの職業探索サービスでは、利用者があらかじめ希望する職種や興味のある分野を指定する必要がある。しかし、将来について考え始めたばかりで、自分の興味や関心がまだ明確でない若者にとって、最初から選択肢を選ぶこと自体が難しい。また、一般的な職業適性検査は、利用者を分析・評価し、適性のある職業を提示することで結論を導く傾向がある。

「しごとくじ」は、くじを引くような感覚で多様な職業や働く人々の人生の物語と出会い、自分の興味や価値観を少しずつ発見していく職業探索プラットフォームである。職業を判定したり、将来を決めたりするのではなく、学生自身の考えを尊重し、自分の意思で進路を選択するための意思決定支援を目指す。

### 製品説明
「しごとくじ」は、職業選択に悩む若者が、多様な仕事や働く人々の人生の物語を通じて、自分の興味や将来の可能性を発見する職業探索プラットフォームである。主な機能は以下の3つである。

#### 1. 未知の職業人生との出会いとリアクション
くじを引くような感覚で、これまで知らなかった職業や働く人々の経験、悩み、転機などの物語に出会い、リアクションを通じて自分の関心を表現する。

#### 2. 自分自身の探索過程の振り返り
これまでに出会った物語やリアクションを振り返り、自分が何に惹かれ、どのような価値観を持っているのかを考えるきっかけを得る。

#### 3. 職業やスキルの可能性の探索
探索の過程で見えてきた興味や関心を手がかりに、関連する職業や必要なスキルの方向性を知り、今後の進路を考える選択肢を広げる。

### 特長
#### 1. 物語から始まる職業探索
最初から「職種の物語」を選ぶのではなく、職種やタイトルを完全に隠します。働く人々の人生の物語を「くじ」として提供し、ユーザーが物語を読む感覚で自然に反応できる仕組みを採用している。

#### 2. 豊富なインタラクションの選択肢
物語をスワイプして興味の有無を示すだけでなく、詳細を読んでから判断したり、キーワードの振り返りで関心の強さを調整したりできる。多様なインタラクションを通じて、ユーザーの意思や関心を丁寧に捉えることを目指す。

#### 3. あらかじめ決められた進路に誘導しない
職業への関心軸やキーワード、職業・スキルの推薦は固定的に設定せず、ユーザーの行動を尊重しながらLLMが継続的に分析・抽出する。特定の進路へ性急に誘導するのではなく、ユーザー自身が適切なタイミングで意思決定できるよう支援する。

### 解決出来ること
職種を指定できるほど自分の興味や関心が明確でない若者は、既存の職業探索サービスでは最初の選択自体に困難を感じやすい。「しごとくじ」は、くじのように出会う職業人生の物語へのリアクションや、探索履歴・キーワードの振り返りを通じて、本人も気づいていない興味や価値観を段階的に可視化する。さらに、その分析をもとに関連する職業や必要なスキルを提示することで、特定の進路に誘導することなく、自分自身で将来を選択するための手がかりを提供する。

### 注力したこと
* LLMを活用したマルチエージェント・パイプラインの導入
* ユーザーの状況に応じた情報提示と自然な反応を促す設計
* 意思決定支援の視点に基づく段階的な探索プロセスの設計
